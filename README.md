# Jollibee Style Food Landing Page

Một giao diện trang bán món ăn theo phong cách Jollibee, làm bằng HTML, CSS và JavaScript cơ bản.

## Mô tả
- Header với logo, menu, thanh tìm kiếm, giỏ hàng và đăng nhập
- Hero banner lớn với slider đơn giản
- Khu vực ưu điểm thương mại
- Best Seller với các card món ăn
- Tương tác JavaScript: slider tự động + tăng số lượng giỏ hàng khi bấm đặt hàng

## Cách chạy
1. Mở file `index.html` trong trình duyệt.
2. Hoặc dùng Live Server nếu bạn đang làm trong VS Code.

## Tệp chính
- `index.html`
- `styles.css`
- `script.js`
